# Dashboard-avec-powerBi

Présentation

Ce projet consiste à créer un tableau de bord interactif avec Power BI pour analyser les ventes et les retours de produits.

Fonctionnalités

- Analyse des ventes réelles et des ventes retournées.
- Suivi des quantités vendues et retournées.
- Classement des produits selon les ventes.
- Analyse des ventes par dépôt et par jour.
- Suivi des performances des vendeurs.
- Utilisation de filtres interactifs.

Outils utilisés

- Microsoft Power BI
- Power Query
- DAX
